# 上传 GitHub

上传目录就是本 README 所在仓库根目录，不要再把它外面的整个学习工作区上传。目录内保留源码、Keil 工程、第三方许可、只读主站、测试、演示视频及一段真实 CSV；已排除虚拟环境、原始录像、历史版本、个人安装路径和编译缓存。

1. 发布前决定原创代码的许可证。目前没有添加原创 LICENSE，也不宣称整个项目采用 MIT。决定后再添加适合的许可和版权信息；第三方许可继续保留。
2. GitHub 新建仓库，名称可用 bms-lite-stm32-freertos。简介可写：STM32 / FreeRTOS 电压电流温度监测、RS485 Modbus 与继电器过温断载实物演示。
3. 将本目录内容提交到该仓库；不要上传外层 ZIP 文件作为唯一仓库内容。
4. README 的视频链接指向约 12.3 MB 的 MP4；GitHub 页面可能显示下载入口，下载后播放即可。需要直接展示时，可在仓库讨论、Issue 或 Release 中另附视频，再自行补充已生成的实际链接。
5. 首次推送后检查 Actions。附带流程只做主机测试；本地通过不等于线上 Actions 已运行。

例如在本目录执行 git init、git add .、git commit 后，使用自己仓库的真实 remote 推送。这里未执行创建远程仓库或推送操作，亦未代为选择发布许可。
