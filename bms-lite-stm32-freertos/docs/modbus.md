# Modbus RTU 映射 0x0502

115200 bit/s，8 数据位、偶校验、1 停止位；从站地址 1；FC03 只读。地址为零基索引，不使用 40001 编号。默认一次读 36 寄存器，主站还兼容旧版 22 寄存器响应。

每个寄存器按 Modbus 高字节在前；32 位字段按低字寄存器在前组合。有符号字段使用二进制补码。

| 地址（hex） | 字段及单位 |
| --- | --- |
| 00 | 总线电压 mV |
| 01 | 有符号温度原始值，除以 16 为 °C |
| 02 | 过温报警 0/1 |
| 03 | 温度状态：0 等待、1 正常、2 缺失、3 CRC 错误 |
| 04 | 系统及继电器指令状态位，见下文 |
| 05–06 | 32 位样本序号，低字在前 |
| 07–08 | 32 位 I²C STOP 超时累计 |
| 09–0A | 当前/历史最低剩余堆字节数 |
| 0B–11 | sample/display/input/alarm/buzzer/uart/modbus 最低剩余栈，单位 4 字节 |
| 12 | 按键计数 |
| 13 | OLED 页码 1～4 |
| 14–15 | 32 位接收错误累计 |
| 16 | 电测有效性位 |
| 17 | 有符号分流电压原始值，2.5 µV/LSB |
| 18 | 有符号电流原始值，250 µA/LSB |
| 19 | 芯片功率原始值，6.25 mW/LSB |
| 1A | 实际读回 CAL |
| 1B–1C | 批次开始/结束 Mask/Enable 读数 |
| 1D–1E | 有符号 32 位电流 µA，低字在前 |
| 1F–20 | 有符号 32 位软件功率 µW，低字在前 |
| 21 | 期望 CAL = 2048 |
| 22 | 分流电阻 µΩ = 10000 |
| 23 | 映射版本 0x0502 |

04 状态：bit0 有样本；bit1 原有 INA 读数有效标志；bit2 温度正常；bit3 样本年龄不超过 1500 ms；bit4 INA ID 正确；bit15 表示包含继电器字段；bit5 为接通指令；bit6～8 是原因：0 等待、1 正常、2 过温、3 传感器异常、4 数据超时。**接通指令不等于触点反馈。**

16 电测位：bit0 全部相关读取成功；bit1 CAL 匹配；bit2 初始化及 ID 正确；bit3 无溢出；bit4 无量程端点异常且总线电压不超过 36 V；bit5 批次开始存在新的转换完成标志；bit6 批次结束未发现转换期间更新。0x007F 表示本批次检查均通过。缺位时主站隐藏电流和功率，不能填作零。瞬间转换跨批次与校准不匹配应分别解释。

## 报文示例（含 CRC，低 CRC 字节在前）

```text
读 36 个：01 03 00 00 00 24 45 D1
读 4 个： 01 03 00 00 00 04 44 09
越界读：  01 03 00 24 00 01 C4 01
异常响应：01 83 02 C0 F1
```

坏 CRC、错误地址或不合帧长度时不响应；不支持功能码返回异常 01，越界返回异常 02。高波特率 RTU 使用 750/1750 µs 基准及 RXNE 完成时间戳补偿；软件状态机有主机测试，但未用示波器完成所有边界时序合规验证。
