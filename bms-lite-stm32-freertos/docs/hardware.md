# 硬件与接线

实测硬件：STM32F103C8T6、INA226（R010，10 mΩ 分流电阻）、DS18B20、I²C OLED、MAX485 模块、USB-RS485、低电平触发 5 V 光耦继电器模块、蜂鸣器、按键及三只 10 Ω / 5 W 串联电阻。三电阻冷态实测约 28.3 Ω。电池为 3S 18650，经独立保护板 P+/P− 输出。

| STM32 引脚 | 连接或功能 |
| --- | --- |
| PA0 | 按键，按下接地，内部上拉 |
| PB0 | DS18B20 数据，开漏；数据线上拉到 3.3 V |
| PB1 | 低电平蜂鸣器控制 |
| PB6 / PB7 | I²C1 SCL / SDA，OLED 0x3C，INA226 0x40 |
| PA9 | USART1 TX → MAX485 DI |
| PA10 | USART1 RX ← MAX485 RO |
| PA1 | MAX485 DE 与 /RE 并接，低接收、高发送 |
| PB12 | 继电器 IN，开漏低电平吸合 |
| PC13 | 板载心跳 LED |

OLED 与 INA226 逻辑供电 3.3 V，所有相关 GND 共地。继电器 DC+ 接稳定 5 V，DC− 接公共地，IN 接 PB12，跳帽在 L 位置。继电器线圈不可从 STM32 的 3.3 V GPIO 供电。接入 GPIO 前拆除 IN 与 DC+ / DC− 的手工测试短接线。

原型使用 MAX485 的 5 V 电源节点给继电器供电，并通过面包板分配。接线时固定电源与接插件。MAX485 的 RO 电平需与实际 STM32 引脚容限匹配；换板、换模块时核对对应器件资料，不能把所有 GPIO 都当作 5 V 容忍引脚。

## 负载回路

```text
保护板 P+ → INA226 VIN → R010 → VOUT → 继电器 COM
继电器 NO → 三只 10Ω / 5W 串联电阻 → 保护板 P−
继电器 NC 不接
公共测量参考地：P−
```

保留保护板 B−、B1、B2、B+ 与三串电芯的原接法，不绕过保护板。接电池测量时移除此前 VIN 接 3.3 V 的测试跳线。INA226 VCC 是逻辑电源，不能接电池正极；电池约 11 V 也不能进入 5 V 或 3.3 V 电源轨。

负载导线接螺丝端子并固定。三只电阻工作时发热，放置在耐热且不会短路的支撑面，与跳线及板子留开距离。修改回路前断开电池和所有 USB 供电；电阻测量只在断电、无残留电压时进行。

## RS485 原型连接

USB-RS485 的 A/B 接 MAX485 对应 A/B，地参考共通。原型配置 A 端约 470 Ω 上拉至 5 V、B 端约 470 Ω 下拉到地，两端约 120 Ω 终端。模块可能自带终端和偏置，复现时检查已有电阻，避免盲目重复叠加。

原型可选 USB-TTL 旁听：仅 RXD 接 PA9、GND 共地；其 TXD、VCC 不接。正常运行不需要该旁听设备。不要让两个设备同时驱动同一 UART 发送线。

本项目未验证充电过程，不提供充电器选型或充电接线流程。
