# 演示视频

[demo.mp4](media/demo.mp4)：46 秒，1920×1080 / 30 fps，H.264 + AAC，带中文硬字幕；[SRT](media/demo.zh-CN.srt) 同时提供。

手机实拍 OLED 与实物，电脑录屏展示主站数据；主段通过约 0.6 秒偏移对齐，前后加入说明页。已裁掉桌面任务栏。声音来自手机原始录音，保留蜂鸣器和现场环境声，经过轻度高通、增益和限幅；没有配音或合成蜂鸣器。

继电器指令与真实测量数值保留原始记录。原始手机录像及桌面录像不随仓库上传，发布文件不携带原手机 GPS 信息。

观看顺序：常温接通 → 加温超过 30°C → 报警、断载、电流近零 → 降至恢复阈值 → 接通负载。
